# Rug Concierge

MVP codebase for AI-powered rug recommendation, trade support, and staff appraisal drafting.

## 15-Minute Onboarding

1. Read `docs/master-context.md`.
2. Read `docs/contributor-map.md`.
3. Install and run:

```bash
npm install
npm run dev
```

4. Run baseline validation:

```bash
npm --workspace apps/web run lint
npm --workspace apps/web run build
```

## Where to Edit

Use the contributor map as the source of truth:

- `docs/contributor-map.md`

Quick docs index:

- `docs/README.md`

## Workspace + Lockfile Policy

- Use npm workspaces from the repo root only.
- Canonical lockfile is:
  - `package-lock.json`
- Do not maintain or commit app-level lockfiles.
- Next Turbopack workspace root is pinned in:
  - `apps/web/next.config.mjs`

## Commands

Run app:

```bash
npm run dev
```

Run smoke:

```bash
SMOKE_TENANT_ID=YOUR_TENANT_ID npm run qa:e2e-smoke
```

## Daily Comprehensive Test

Run one command for full validation:

```bash
SMOKE_TENANT_ID=YOUR_TENANT_ID npm run qa:all
```

Read first:
- `docs/testing/latest-summary.md`

Deep debug (only if needed):
- `docs/testing/e2e-smoke-report.md`
- `docs/testing/demo-rehearsal-report.md`
- `docs/testing/artifacts/`

Testing guide:
- `docs/testing/README.md`

Note:
- Test report files are generated by scripts and may not be present until you run `npm run qa:all` or related test commands.
