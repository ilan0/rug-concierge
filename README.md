# rug-concierge

Docs: docs/README.md

## Requirements
- Node.js >= 20.9.0

## Quick Start

1. Install deps

```bash
npm install
```

2. Run the web app

```bash
npm run dev
```

The Next.js app lives in `apps/web`.

## Validation

```bash
npm --workspace apps/web run lint
npm --workspace apps/web run build
```
